## 🌟 Key Features

* **Effortless LAN Sharing:** Once the app is active, it serves your files directly over HTTP. Any computer or mobile device on the same Wi-Fi can instantly connect.
* **Dual Browse UI:** Manage and access your shared files securely within the app on your Android device, or through a beautiful, intuitive web interface on any connected computer.
* **Quick In-App Transfers:**
  * **Upload:** Choose files from your phone's storage to quickly add them to your shared folder.
  * **Paste:** Copy text on your phone and automatically paste it into a new .txt file within the shared folder!
* **Blazing Fast Speeds:** Uses your local network bandwidth, ensuring the fastest possible file transfer speeds.
